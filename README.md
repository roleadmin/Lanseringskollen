# Lanseringskollen

Gratis kvalitetschecklista på svenska för appar byggda med AI-verktyg som Lovable, Claude Code och Bolt.

25 kontrollpunkter i sex grupper: personuppgifter och GDPR, cookies, inloggning, hemliga nycklar, databas och testning. Varje punkt har en prioritet (stoppunkt, viktig, bra att ha), och sidan räknar fram ett lanseringsbetyg och en åtgärdslista.

## Så fungerar den
- En enda fil: `index.html`. Ingen server, ingen databas, inga cookies.
- Svaren sparas bara i besökarens egen webbläsare.

## Publicering
Sidan publiceras med GitHub Pages från grenen `main`.

## Ansvarsfriskrivning
Detta är en kvalitetschecklista, inte en säkerhetsgranskning eller juridisk rådgivning.
